# Spiritbound audio

`forest_whisper.wav` is **Forest Whisper Theme** by **Cleyton Kauffman**.

- Source and download: https://opengameart.org/content/forest-whisper-theme
- Composer: https://soundcloud.com/cleytonkauffman
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)

The supplied WAV is unchanged. Its Godot import enables forward looping over the
whole track and uses Godot's default QOA compression. Keep the `.wav.import`
file with the source so exports use the same loop settings.

`game/room_audio.gd` synthesizes the short animal movement, trunk pushing,
possession, splash, and completion cues. Those cues require no external samples.
